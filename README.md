# Task 26 – Text Cleaning Basics

## Project Overview
This project focuses on cleaning and standardizing customer text data using Excel and Python.

## Objectives
- Standardize customer names.
- Remove unnecessary spaces.
- Correct inconsistent capitalization.
- Standardize email formatting.
- Normalize employment types.
- Improve dataset consistency.

## Tools Used
- Microsoft Excel
- Python
- Pandas

## Deliverables
1. Complete Excel workbook.
2. Cleaned customer dataset (CSV).
3. Before-and-after cleaning examples.
4. Cleaning log.

## Data Cleaning Operations
- Removed leading and trailing spaces.
- Corrected inconsistent capitalization.
- Standardized customer names.
- Converted emails to lowercase.
- Standardized city names.
- Normalized employment categories.

## Project Files
- `Task_26_Text_Cleaning_Basics.xlsx`
- `Task_26_Cleaned_Customer_Dataset.csv`
- `Task_26_Before_After_Examples.csv`

## Note
The dataset contains synthetic sample customer records created for demonstration and practice purposes.

## Outcome
Successfully demonstrated fundamental text-cleaning techniques and produced a standardized customer dataset.
